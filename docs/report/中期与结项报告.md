## 一、项目目标回顾（对照计划书）

根据《项目计划书》与课堂要求，本系统拟实现：

1. **角色与登录**：管理员与普通读者分角色登录；具备权限区分与退出登录能力。  
2. **核心业务**：图书管理、读者管理、借阅管理三大模块的基础 **增删改查**。  
3. **查询与状态**：支持图书按书名等条件检索；借阅相关状态随业务更新。  
4. **非功能**：可在课堂环境下稳定演示；基本安全与浏览器兼容（Chrome / Edge）。  

技术路线：**Vue3（组合式 API）+ Element Plus + Axios** 前端，**Spring Boot 3 + MyBatis** 后端，数据库以 **MySQL 8** 为主（开发阶段可使用 H2 等便于联调）。

### 2.2 组长（赵云扬）已完成工作摘要

- 前端 **登录模块**（表单校验、调用 `/api/user/login`、本地会话与 Token 兼容策略）。

- 工程化：`auth` 工具模块、`request` 拦截器（含 Bearer Token）、`.gitignore` 与依赖锁定等协作基础。

## 三、主要风险与应对措施

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 前后端接口字段不一致 | 联调失败、演示卡顿 | 维护简单接口说明（路径、请求体、响应 code/data）；组长组织一次联调会议。 |
| 鉴权方案未统一（Session / JWT） | 守卫与请求头行为不一致 | 与后端约定：是否下发 `token`、Header 名称、401 时前端是否统一跳登录。 |
| 业务页开发滞后 | 无法展示完整 CRUD | 按优先级先保证「一条完整借阅闭环」再扩展界面美化。 |
| 数据库环境差异（H2 / MySQL） | 部署与演示环境不一致 | 结项前固定一套演示环境（含初始化 SQL）。 |

## 四、结项阶段工作计划

1. **功能闭环**：完成图书、读者、借阅在前端的页面与后端接口联调，满足计划书「可演示、无致命缺陷」底线。  
2. **角色与权限**：在真实页面上验证管理员与读者可见菜单及接口权限（与路由守卫策略一致）。  
3. **数据与脚本**：提供可重复执行的建表与基础数据脚本，便于验收复现。  
4. **文档与材料**：更新 README 或部署说明；完善本报告「结项总结」段落；按课程要求整理 PPT 与演示录屏（如需）。  
5. **测试与收尾**：主流程走查（登录 → 各角色菜单 → 核心业务操作 → 退出）；修复阻塞级 Bug。
